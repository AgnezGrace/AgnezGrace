## 📖 Overview

Welcome to **LUNARICA**, the primary open-source and software demonstration workspace curated by **Agnez Grace**. 

Our engineering focus centers on building lightweight, zero-telemetry, client-side web applications and mathematical simulators. By leveraging modern Web APIs—such as **IndexedDB**, **Web Crypto API (AES-GCM)**, **HTML5 Canvas**, and **Service Worker PWAs**—we craft standalone tools that require zero backend server overhead while providing complete user privacy and desktop-grade performance.

## 🚀 Featured Software & Engines

### 🌌 [Cosmic Spirograph]
*Advanced Geometric Motion Engine*
- **Mathematical Modeling:** Real-time parametric simulation modeling Hypotrochoid and Epitrochoid mechanical physics.
- **Harmonic Helper Gears:** Multi-frequency gear layering with friction phase damping and dynamic canvas rotation.
- **Ultra-Res Rendering:** Live color mode generation (Single, Gradient, Animated HSL) with lossless PNG rendering exports up to **4K resolution (4000px)**.

### 🎭 [Chat Fiction Engine]
*Interactive Branching Narrative & Encryption Suite*
- **Encrypted Export (.LNRC):** Proprietary AES-GCM (SHA-256) story serialization with granular permission locks (*Play Only*, *Profile Edit*, or *Full Access*).
- **Node Branch Map:** Interactive visual narrative tree for jumping across narrative decision nodes.
- **Simulated Media Calls:** Voice/video call simulation with visual feedback and typing delay engines.

### 🖼️ [Aruna Gallery & Vault]
*Privacy-First Ultra-HD Media Vault & Canvas Editor*
- **Local Vaulting:** High-resolution image indexing and album management backed by IndexedDB with zero external server uploads.
- **In-Browser Photo Editor:** Full crop engine, spatial transformation (-90°/+90°, horizontal/vertical flip), fine adjustment sliders, and preset filter matrices.
- **Lossless Backup System:** Compressed `.zip` vault export and import utility retaining complete metadata and resolution fidelity.

### 📝 [You Okay?]
*Minimalist Glassmorphism Note Engine*
- **Ambient Glass Design:** Responsive, high-contrast ambient UI featuring folder trees, pinned states, and real-time text telemetry.
- **Local Persistence:** Client-side document storage built with IndexedDB, real-time autosave indicators, and instant full-text filtering.

### 📚 [Tsuna & Yours Studio]
*Client-Side Novel Drafting & Cover Creation Suite*
- **Cover Layout Generator:** Custom gradient presets, typographic hierarchy engines, and user gallery image uploads.
- **Drafting Workspace:** Rich-text chapter editors equipped with theme paletting (Sage, Lavender, Berry, Ocean), real-time word counters, and JSON library backups.

### 🏛️ [ETHOS]
*High-Contrast Personal Philosophy & Portfolio Hub*
- **Systemic Logic Showcase:** A curated digital archive exploring design restraint, high-contrast monochrome aesthetics, and open-source project indexing.

## 📐 Engineering Philosophy

1. **Zero-Backend Data Ownership:** All user data, stories, media, and notes remain encrypted or stored locally on the user's client device.
2. **Framework Restraint:** Avoiding runtime bloat by engineering complex applications with native Vanilla JS, producing near-instant load times and zero dependency vulnerabilities.
3. **Aesthetic Precision:** High contrast, glassmorphism UI palettes, custom HSV color selection, and responsive touch gestures optimized across all screen sizes.
